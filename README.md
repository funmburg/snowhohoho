# Снегопад

Новогоднее настроение для Windows: снег идёт прямо поверх рабочего стола.

- Снежинки падают поверх всех окон и не мешают работать — клики проходят насквозь.
- Снег ложится сугробами на верхние края окон и на панель задач. Сдвинешь окно — снег осыплется.
- Когда панель задач завалит, по ней проедет снегоуборщик.
- На панели задач появляются снежки. Их можно брать мышкой и ставить друг на друга: три снежка — снеговик.
- На окнах висят мигающие гирлянды.

## Скачать

Готовый `Snegopad.exe` лежит в разделе [Releases](../../releases). Установка не нужна: скачал и запустил.

Windows может показать предупреждение SmartScreen, потому что файл не подписан: «Подробнее» → «Выполнить в любом случае».

Нужна Windows 10 или 11.

## Управление

Значок-снежинка в трее (возле часов), правая кнопка мыши:

- пауза;
- количество снега: мало, средне, много;
- гирлянды, снежки, снегоуборщик — включить или выключить;
- вызвать снегоуборщик, стряхнуть снег, убрать снежки;
- экономный режим (30 кадров в секунду);
- пауза в играх и полноэкранном видео (включена по умолчанию);
- запуск вместе с Windows;
- выход.

Аварийный выход с клавиатуры: `Ctrl + Alt + Shift + Q`.

## Нагрузка на компьютер

- Написано на C++ без сторонних библиотек: Win32, Direct2D и DirectComposition. Рисует видеокарта.
- В играх и полноэкранном видео программа сама встаёт на паузу и ничего не рисует.
- Список окон обновляется 4 раза в секунду, а не каждый кадр.
- Перехват мыши включается, только когда курсор рядом со снежком.

## Сборка из исходников

Нужны Visual Studio 2022 (компонент «Разработка классических приложений на C++») и CMake.

```
cmake -B build -A x64
cmake --build build --config Release
```

Готовый файл: `build\Release\Snegopad.exe`.

Каждый коммит в `main` также собирается автоматически через GitHub Actions.
